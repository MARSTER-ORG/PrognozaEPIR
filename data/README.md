# EPIR Fog observation archive

`fog-observations.jsonl` is created automatically after the first archived observation.
Each line is one independent JSON record containing:

- observation time and location,
- measured air temperature,
- measured dew point,
- derived relative humidity,
- measured visibility in metres,
- EPIR Fog Engine forecast snapshot captured before assimilation of the observation,
- application/engine versions and archive metadata.

The archive is intended for later verification and calibration of EPIR Fog Engine (bias analysis, Brier/CSI verification, logistic/isotonic calibration and future ML/XGBoost experiments).

Observations are submitted through a pre-filled GitHub Issue generated by the PrognozaEPIR page. The `Archive EPIR fog observation` workflow validates the payload, appends it to `data/fog-observations.jsonl`, commits it to `main`, then closes the Issue.

This repository is public, so archived meteorological observations are public. The JSONL archive intentionally does not store the GitHub username of the observer.
