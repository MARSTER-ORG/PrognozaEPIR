# ICM Vision — izolowany prototyp

Prototyp odczytu ręcznie dostarczonego obrazu meteogramu przez Gemini Vision. Nie pobiera automatycznie danych z ICM, nie zmienia Consensus, TAF ani silników mgły i nie zapisuje prognoz w bazie.

Test dopiero po dostarczeniu obrazu z czytelną legendą i osią czasu. Źródło ICM, prawa do danych i zasady ich automatycznego wykorzystywania wymagają weryfikacji: https://faq.meteo.pl/.

Wyniki z Gemini zawsze podlegają walidacji jednostek, czasu UTC, braków danych i zakresów fizycznych; nie wolno wyprowadzać widzialności z samej wilgotności. Nie służą jako dane operacyjne.
